# Classroom apps

| Folder | What it is |
|---|---|
| [`chem-escape/`](chem-escape/) | **The Thistlewood Game Works**: a browser-based narrative escape game for Year 10 Chemistry. Open `chem-escape/index.html` to play. See its [README](chem-escape/README.md) for teacher notes and the answer key. |

To deploy on Vercel, set the project's Root Directory to `chem-escape` and the Framework Preset to "Other".
